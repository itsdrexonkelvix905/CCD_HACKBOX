## Versioning Policy

CCD_HACKBOX uses semantic versioning:

- **MAJOR:** Significant architectural changes or incompatible releases.
- **MINOR:** New modules, challenges, or major features.
- **PATCH:** Bug fixes, documentation corrections, and minor improvements.

## Release Notes

A release should only be published after:

- Challenge functionality has been tested.
- Installation procedures have been verified.
- Sensitive instructor data has been excluded.
- Network isolation has been checked.
- Documentation matches the actual release.
- Appliance integrity has been verified.
