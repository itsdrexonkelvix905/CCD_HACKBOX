# Contributing to CCD_HACKBOX

Thank you for contributing to CCD_HACKBOX.

## Contribution Guidelines

- Follow the existing project structure.
- Write clear and maintainable documentation.
- Use verified technical references.
- Test scripts and configurations in an isolated environment.
- Document dependencies and compatibility requirements.
- Do not submit real credentials, secrets or private flags.
- Do not introduce unauthorized or unsafe functionality.

## Reporting Issues

When reporting an issue, include:
- A clear description.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Relevant logs or screenshots.

## Pull Requests

1. Create a separate branch.
2. Make focused changes.
3. Test your changes.
4. Provide a clear description.
5. Submit a pull request for review.

All contributions must support authorized cybersecurity education.
