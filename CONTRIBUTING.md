
# Contributing to CCD_HACKBOX

Thank you for your interest in contributing to CCD_HACKBOX.

CCD_HACKBOX is an educational Linux privilege escalation training environment developed for authorized cybersecurity learning and practical security exercises.

## Contribution Scope

Contributions may include:

- Improving project documentation.
- Fixing configuration and deployment issues.
- Improving existing lab reliability.
- Developing new Linux privilege escalation challenges.
- Improving network isolation and lab safety.
- Adding setup and troubleshooting instructions.
- Reporting bugs and suggesting improvements.

## Contribution Guidelines

All contributions must:

1. Be intended for authorized educational use.
2. Be tested in an isolated lab environment.
3. Include clear documentation.
4. Avoid exposing real credentials, private keys or instructor flags.
5. Avoid destructive changes outside the lab environment.
6. Include reset or cleanup instructions where applicable.

## Development Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test the changes in an isolated environment.
5. Update relevant documentation.
6. Submit a Pull Request.

Example branch names:

- `docs/improve-lab-guide`
- `feature/add-new-challenge`
- `fix/pe06-cron-config`

## Challenge Submission Requirements

Every new challenge should document:

- Challenge ID and title.
- Learning objective.
- Required starting environment.
- Starting user or access level.
- Relevant system configuration.
- Expected challenge behavior.
- Verification method.
- Reset and cleanup procedure.
- References and learning resources.

Do not include real challenge flags or instructor-only walkthroughs in public submissions.

## Code and Script Safety

Scripts submitted to this project should:

- Be understandable and documented.
- Avoid unnecessary system-wide modifications.
- Avoid downloading and executing untrusted remote content.
- Include safe cleanup procedures.
- Be tested before submission.

## Pull Request Checklist

Before submitting a Pull Request, confirm:

- [ ] The change is related to CCD_HACKBOX.
- [ ] Documentation has been updated.
- [ ] Changes have been tested.
- [ ] No private credentials or flags are included.
- [ ] No unrelated system files are modified.
- [ ] Reset instructions are included where necessary.

## Code of Conduct

Contributors are expected to act professionally, respect other contributors and use the project responsibly.

## Disclaimer

CCD_HACKBOX is intended for authorized cybersecurity education and isolated laboratory practice only.
