# Security Policy

CCD_HACKBOX is an intentionally vulnerable cybersecurity training appliance.

## Scope

Security reports may concern:
- Vulnerabilities in project scripts.
- Unsafe installation procedures.
- Accidental exposure of credentials or secrets.
- Security issues in project documentation.
- Unintended access outside the isolated lab.

## Reporting

Report security issues privately to the project maintainers.

Do not publish sensitive exploit details, credentials or private flags in public issues.

## Responsible Use

- Test only within authorized environments.
- Keep vulnerable services isolated.
- Never expose the appliance to production networks.
- Do not use this project to access systems without permission.

## Supported Versions

Development and release support will be documented as versions become available.
