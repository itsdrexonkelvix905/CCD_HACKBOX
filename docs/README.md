## Intended Audience

This documentation is intended for:

- Cybersecurity students.
- Linux learners.
- Ethical hacking trainees.
- Lab administrators.
- Project contributors.
- Instructors.

## Documentation Principles

Documentation should be:

- Accurate and easy to follow.
- Consistent with the actual lab implementation.
- Safe for public distribution.
- Updated whenever the project changes.

Instructor-only credentials, flags and private walkthroughs must remain outside public documentation.
